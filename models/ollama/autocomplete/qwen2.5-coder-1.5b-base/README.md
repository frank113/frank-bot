# Qwen2.5-coder-1.5-base

This model is a suggested autocomplete model. In a regular workflow this model is:

+ Lightweight
+ Reasonably accurate: Can be tuned with some simple configurations
+ Good enough that it will not destroy my battery for local use

My intent with this model is to attain 70% of Cursor's industry-leading autocomplete functionality.

## Battery Variant

I created a `battery` variant of the model in `Modelfile.2k.battery`.
